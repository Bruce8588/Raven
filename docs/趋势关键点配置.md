# 趋势关键点配置

**来源**：智算系统趋势体系详解文档
**更新时间**：2026-03-31

---

## 各趋势需要的完整关键点

### 上升体系

| 趋势 | 中文 | 需要的完整关键点 |
|------|------|-----------------|
| **up** | 上升趋势 | key_high（关键高点） |
| **up_natural** | 自然回撤 | n_low（自然回撤低点） |
| **up_rally** | 回升 | n_low, key_high, rally_high |
| **up_secondary** | 次级回撤 | n_low, rally_high, secondary_low |
| **up_break** | 上升破碎 | n_low, break_low |

### 下跌体系

| 趋势 | 中文 | 需要的完整关键点 |
|------|------|-----------------|
| **down** | 下跌趋势 | key_low（关键低点） |
| **down_natural** | 自然回升 | n_high（自然回升高点） |
| **down_rally** | 回撤 | n_high, key_low, rally_low |
| **down_secondary** | 次级回升 | n_high, rally_low, secondary_high |
| **down_break** | 下跌破碎 | n_high, break_high |

## 关键点代号说明

| 代号 | 中文名 | 含义 |
|------|--------|------|
| key_high | 关键高点 | 上升趋势的最高点 |
| key_low | 关键低点 | 下跌趋势的最低点 |
| n_low | 自然回撤低点 | 自然回撤的最低点 |
| n_high | 自然回升高点 | 自然回升的最高点 |
| rally_high | 回升高点 | 回升趋势的最高点 |
| rally_low | 回撤低点 | 回撤趋势的最低点 |
| secondary_low | 次级回撤低点 | 次级回撤的最低点 |
| secondary_high | 次级回升高点 | 次级回升的最高点 |
| break_low | 破碎低点 | 破碎趋势的最低点 |
| break_high | 破碎高点 | 破碎趋势的最高点 |

## 6%规则

趋势系统使用**6%**作为判断幅度：

| 乘数 | 含义 | 用法 |
|------|------|------|
| × 0.94 | 下跌6% | 当价格跌破关键点的94%时触发 |
| × 1.06 | 上涨6% | 当价格涨破关键点的106%时触发 |
